# FMCG Power BI Mini Projects

This repository contains two Power BI mini projects developed for analysing FMCG business data. The projects focus on sales performance and distribution performance using interactive dashboards created in Microsoft Power BI.

##  Projects

### 1. FMCG Sales Analysis Dashboard

This dashboard analyses FMCG sales performance using sales, profit, products, categories, sales channels and state-wise data.

#### Key Features

- Total Sales
- Total Profit
- Total Units Sold
- Total Orders
- Profit Margin
- Monthly Sales Trend
- Sales Channel Analysis
- Product Category Analysis
- Top 5 Products by Sales
- State-wise Sales Analysis
- Interactive Filters and Slicers

#### Dataset

**File:** `FMCG_Sales_Dataset_project_1.xlsx`

- 9 sheets
- 4,000 sales transactions
- Data period: January 2025 – December 2026
- Includes sales, product, distributor, retailer, customer, target and inventory information.

#### Tools Used

- Microsoft Power BI Desktop
- Microsoft Excel
- Power Query
- DAX

#### Dashboard Preview

![FMCG Sales Dashboard](FMCG_Sales_Analysis_Dashboard/Screenshots/Sales_Dashboard.png)

### 2. FMCG Distribution Performance Dashboard

This dashboard focuses on FMCG distribution and operational performance. It compares actual sales with targets and analyses distributors, distribution channels, regions, orders and returns.

#### Key Features

- Net Sales
- Target Sales
- Target Achievement %
- Total Orders
- Total Distributors
- Return Rate
- Monthly Target vs Actual Sales
- Distribution Channel Analysis
- Distributor-wise Sales
- Order Status Analysis
- Regional Payment Mode Analysis
- Interactive Filters and Slicers

#### Dataset

**File:** `FMCG_dataset_project_2.csv`

- 4,000 orders
- 26 columns
- Data period: January 2024 – December 2024
- Includes distributor, outlet, product, sales, target, order status, return and distribution-channel information.

#### Tools Used

- Microsoft Power BI Desktop
- Power Query
- DAX
- CSV Dataset

#### Dashboard Preview

![FMCG Distribution Dashboard](FMCG_Distribution_Performance_Dashboard/Screenshots/Distribution_Dashboard.png)
